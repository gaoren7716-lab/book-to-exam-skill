## 3. 零填空扫描

⚠️ **扫题库内容，不要扫整份 HTML**。整份 HTML 必然误报：
JS 函数调用 `selectWeak()` 命中「空括号」、快捷键提示「回车/空格进入下一题」命中「空格」。

```bash
python -c "
import json,re
pats=[r'_{2,}',r'＿+',r'[（(]\s*[）)]',r'填空',r'空缺处',r'依次应填',r'请填写',r'请简述|请回答|试述|试填写',r'被填进|被填入|填入的是|填进去的词',r'横线|空格|划掉|此处填|方括号']
c=json.load(open('考点知识库.json',encoding='utf-8'))
bad=0
for x in c:
    scan=' '.join([x['question'],x['explanation']]+x['options'])
    hit=[p for p in pats if re.search(p,scan)]
    if hit: print(x['id'],hit); bad+=1
print('命中:',bad,'->','无命中 ✅' if not bad else '需返工 ❌')
"
```

- [ ] 题库内容零命中

反向验证（防止守卫被削弱）：

```bash
python -c "
import re
pats=[r'_{2,}',r'＿+',r'[（(]\s*[）)]',r'填空',r'依次应填',r'请简述',r'被填进|填进去的词',r'横线|空格']

```

必须 6/6 全部命中。若有漏网，说明正则被削弱了。
