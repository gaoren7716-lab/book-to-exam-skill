📖 book-to-exam

把一本书，变成一套可以考核的系统
知识框架 → 纯选择题库 → 交互式考试网页 → Anki 闪卡
▶ 打开演示考试系统 GitHub 仓库
考过设定分数线，即视为掌握全书。 演示数据是本项目虚构编写的示例书（48 题 / 4 章 / 22 知识点），点开就能直接考，无需安装任何东西。

全程零输入框

全部为点选式选择题。不填空、不简答、不要求手打长文本。构建脚本用高精度正则拦截，连「无横线的填空思维化石」也会拒收。

大纲即学习路径

三级折叠：部分 → 章 → 知识点。勾选感兴趣的知识点，考试范围 = 大纲选中 ∩ 章节勾选 ∩ 题型筛选，首页明写当前题量。

考过才算掌握

默认 90 分线，错题自动进错题本、答对移出，结果页给总分 + 分章正确率。进度可导出 / 导入，换设备不丢。

单文件自包含

考试网页是一个 HTML 文件，零外部请求、零 CDN。扔到任意静态托管即可上线，本页就是证明。

三步上手

git clone https://github.com/gaoren7716-lab/book-to-exam-skill.git
cd book-to-exam-skill

# ① 跑一遍自带演示数据
python book-to-exam/scripts/build_exam.py \
  --book-dir "examples/demo-节奏管理" \
  --title "《节奏管理》" --subtitle "示例自编" --pass-score 90

# ② 打开产物开始考
start examples/demo-节奏管理/考试系统.html

# ③ 跑交互回归（需要 Node）
node tools/regression_test.js

做自己的书

想要建议
自己用，快速出题本地书架网页：python book-to-exam/scripts/书架.py "E:\0 书架"
命令行切章python book-to-exam/scripts/split_book.py 书名.epub --out ./书名（PDF / EPUB / TXT / MD）
发给别人用静态网页部署，零改动
一个技术现实：切章脚本能做，但「哪句是核心方法、哪个案例能出场景题、干扰项该取哪章的术语」必须 AI 读懂原文。 分工是：脚本把书拆干净，AI 把书读懂。所以网页不会「一键出考试系统」，它省掉的是记路径、找书、开终端这些事。
